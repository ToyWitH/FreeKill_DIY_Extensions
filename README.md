# 新月杀 DIY 武将扩展

面向新月杀（FreeKill）的 DIY 武将扩展合集，持续收录原创武将、技能实现与立绘，并提供安装包、一键更新和联机兼容说明。当前收录孙佳乐系列，后续可逐步加入其他人物与扩展主题。

当前支持 **新月杀 v0.5.25 / Windows 64 位**。本仓库的扩展与兼容补丁按该版本制作。

## 当前武将

| --- | --- | --- | --- | --- |
| 神·孙佳乐 | 大胃菌王 | 神 | 4 / 4 | 逆天、唐氏、狗运、影黎 |
| 威·孙佳乐 | 风卷残云 | 魏 | 4 / 8 | 卷噬、暴餮 |

## 下载与安装

**首次使用**：下载[完整懒人包](https://github.com/ToyWitH/FreeKill_DIY_Extensions/releases/download/v0.2.3/FreeKill-Sunjiale-Portable-v0.2.3.zip)，完整解压后双击「双击启动.cmd」。游戏、当前武将与兼容补丁已经装好。该懒人包为 v0.2.3，首次启动前可双击更新到最新版本。

**已有懒人包**：完全关闭游戏 → 双击「双击更新.cmd」→ 等待成功 → 重新启动。无需 GitHub 账号，无需再次下载完整游戏。更新保留账号、设置、录像和其他扩展，失败时自动恢复；上一版备份位于游戏目录 `update-backups`。

**已有新月杀 v0.5.25**：在[最新发布](https://github.com/ToyWitH/FreeKill_DIY_Extensions/releases/latest)下载小型扩展包 `FreeKill_diy_sunjiale-v版本.zip`，解压后首次安装：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\安装扩展.ps1 -GamePath "C:\你的游戏目录\FreeKill-release"
```

游戏目录应包含 `FreeKill.exe`。安装器检测到同名扩展或不匹配的游戏文件时会停止；没有更新入口的旧安装建议换用懒人包。详见[安装说明](安装说明.txt)。

## 技能与操作

### 神·孙佳乐

自己的手牌对自己暗置，装备区保持明置。使用或响应暗置手牌时点击「狗运」，先声明，再选择牌背；当前无法合法使用或响应的声明仍显示，但不可选。

普通杀、火杀、雷杀统一声明「杀」，实际属性不变。觉醒后声明基本牌、装备牌、一般锦囊牌或特殊锦囊牌；特殊锦囊指延时锦囊。

逆天的用牌不发动狗运、不计觉醒次数；狗运成功使用或打出牌时计数，增效不另计数。暗置牌不提供重铸入口。延时锦囊暂不支持狗运新增目标。

### 威·孙佳乐

- **卷噬**：出牌阶段，你可以失去1点体力，然后从牌堆中获得一张红桃基本牌。
- **暴餮**：连招技（【桃】→【杀】），出牌阶段，完成此连招的【杀】结算结束后，你本回合使用【杀】的次数上限+1，然后从牌堆中获得X张黑色牌（X为你的体力值）。

同一出牌阶段连续使用桃、杀后自动发动，属性杀也可完成。每组连招可发动一次，加杀次数本回合叠加；中间使用其他牌会中断，卷噬不会打断。只从牌堆取牌，数量不足时获得剩余符合条件的牌。

## 多人联机

服务器与所有客户端需要安装相同版本的扩展及兼容补丁。连接组织者提供的服务器，进入同一房间，并确认房间允许使用相应扩展武将。

客户端安装扩展不能让任意公共服务器自动支持这些武将。本仓库未提供已部署的公网服务器；完整 GUI 对局与多人实战尚未验证。

## 新增武将与维护

武将命名、技能写法及最小实现原则统一遵循[武将与技能规范](武将与技能规范.md)；新增文件、验证与发布流程见[贡献与扩展指南](CONTRIBUTING.md)。武将列表与技能说明随新增内容一起维护。

当前仓库根目录就是游戏扩展目录的源码：

| 位置 | 用途 |
| --- | --- |
| `init.lua` | 注册武将与技能 |
| `skills/` | 技能实现 |
| `translations.lua` | 名称、称号、技能描述与提示 |
| `image/generals/` | 武将立绘 |
| `武将与技能规范.md` | 标签、技能文案与最小实现规则 |
| `武将设计.md` | 当前武将规则与结算约定 |
| `client-patches/` | 当前兼容补丁与校验清单 |
| `tests/` | 技能、客户端、结算和更新器检查 |
| `tools/build_release.py` | 构建带校验清单的扩展包 |
| `updater/` | 玩家一键更新入口 |

为保持已有玩家的安装与更新兼容，当前游戏目录 `packages/diy_sunjiale`、更新脚本文件名和小型安装包文件名沿用历史标识；它们不限制仓库收录更多武将。若以后拆分独立扩展目录，需要同时调整打包、安装、更新与测试。

## 发布与更新

把通过检查的源码提交到默认分支 `codex/initial-import`，GitHub Actions 会自动构建并发布稳定版本 `v0.2.运行编号`。朋友双击更新即可获取最新稳定 Release；仅上传源码需要等待自动发布成功。

更新器校验 GitHub 提供的 SHA256 和包内逐文件清单。当前更新范围是本仓库的武将扩展、5个兼容文件和更新入口；不会自动升级新月杀本体。游戏本体升级需另行制作匹配的补丁与懒人包。

仓库原名 `FreeKill_diy_sunjiale`，现名 `FreeKill_DIY_Extensions`。旧链接通过 GitHub 跳转继续访问；新版本更新器直接使用新地址。

## 检查范围

已通过37项技能场景、Lua 5.4语法与核心注册检查、6项实际客户端检查，以及4项游戏自带框架的服务器结算检查。后者覆盖卷噬扣血取牌、属性杀连招、重复连招、回合清除、连招打断和牌堆不足。

将 `tests/client_module_path.lua` 或 `tests/wei_integration.lua` 复制到已安装游戏的 `test/lua/`，可分别运行：

```text
FreeKill.exe --testfile test/lua/client_module_path.lua
FreeKill.exe --testfile test/lua/wei_integration.lua
```

更新器已检查首次安装、升级、重复运行、个人数据保留、校验失败、不安全路径、补丁冲突、写入失败回滚、下一版补丁及防降级。部分开发测试需要完整开发工作区与原版游戏文件。
