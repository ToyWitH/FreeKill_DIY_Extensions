# 新月杀 DIY 武将扩展

面向新月杀（FreeKill）的 DIY 武将扩展合集，持续收录原创武将、技能实现与立绘，并提供安装包、一键更新和联机兼容说明。当前收录孙佳乐系列，后续可逐步加入其他人物与扩展主题。

当前支持 **新月杀 v0.5.25 / Windows 64 位**。本仓库的扩展与兼容补丁按该版本制作。

完整技能描述与设计约定见 [武将设计.md](武将设计.md)。武将的实际显示名称和技能说明以游戏内为准。

有版本标签的名称统一为“标签·姓名”，普通版本直接显示姓名。卡牌右下角的扩展包类别统一显示“DIY武将”。立绘以人物主体居中的竖版构图呈现；同名转换等小头像使用独立的正方形脸部图片。

## 下载与安装

**首次使用**：下载[完整懒人包](https://github.com/ToyWitH/FreeKill_DIY_Extensions/releases/download/v0.2.3/FreeKill-Sunjiale-Portable-v0.2.3.zip)，完整解压后双击「双击启动.cmd」。游戏、当前武将与兼容补丁已经装好。该懒人包为 v0.2.3，首次启动前可双击更新到最新版本。

**已有懒人包**：完全关闭游戏 → 双击「双击更新.cmd」→ 等待成功 → 重新启动。无需 GitHub 账号，无需再次下载完整游戏。更新保留账号、设置、录像和其他扩展，失败时自动恢复；上一版备份位于游戏目录 `update-backups`。

**已有新月杀 v0.5.25**：在[最新发布](https://github.com/ToyWitH/FreeKill_DIY_Extensions/releases/latest)下载小型扩展包 `FreeKill_diy_sunjiale-v版本.zip`，解压后首次安装：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\安装扩展.ps1 -GamePath "C:\你的游戏目录\FreeKill-release"
```

游戏目录应包含 `FreeKill.exe`。安装器检测到同名扩展或不匹配的游戏文件时会停止；没有更新入口的旧安装建议换用懒人包。详见[安装说明](安装说明.txt)。

## 技能与操作

### 神·孙佳乐

**技能说明**

- **逆天**：锁定技，你的回合开始前，你将一张手牌或装备区里的牌当一张锦囊牌仅对自己使用；一名角色的判定牌生效前，你展示并明置一张暗置手牌：若其与判定牌颜色相同，令此判定失效；否则，你获得判定牌。
- **唐氏**：锁定技，你的手牌对你暗置，且暗置手牌不计入手牌上限。当你失去或明置最后一张暗置手牌后，你失去1点体力，然后摸X张牌（X为你的体力上限）。
- **狗运**：使用或打出暗置手牌前，你须声明牌名，并展示和明置此牌。若声明有误或此牌不符合使用或打出条件，你弃置之，视为未使用或打出。以此法使用牌时，你可以：基本牌，令其多结算一次或弃置场上一张牌；锦囊牌，增减一个合法目标或弃置场上一张牌；装备牌，移动场上一张牌。
- **影黎**：觉醒技，准备阶段开始时，若你已以〖狗运〗使用或打出至少X张牌（X为你的体力上限），你减1点体力上限，然后回复1点体力。此后〖狗运〗改为声明基本牌、装备牌、普通锦囊牌或特殊（延时）锦囊牌。

**操作要点**

- 使用或打出暗置手牌均点击「狗运」，先声明，再选择牌背。当前不能合法使用或打出的选项仍显示，但不可选；要求【闪】时只能声明【闪】，不能主动在出牌阶段使用【闪】。
- 使用真实牌，保留其属性、效果及附加信息；使用次数和合法目标仍受引擎限制。
- 觉醒后声明「基本牌／装备牌／普通锦囊牌／特殊（延时）锦囊牌」。普通锦囊牌指非延时锦囊，特殊（延时）锦囊牌指延时锦囊。猜对类型后，真实牌仍须符合本次使用或打出条件。
- 仅手牌对自己暗置，装备区保持明置。暗置手牌不提供重铸入口；明置手牌仍按原规则重铸。
- 逆天的用牌独立结算，不发动狗运，也不计入其累计次数。狗运成功使用或打出的牌计数；选择、取消或执行增效不另计数，单纯打出不增效。场上牌指装备区和判定区的牌；延时锦囊暂不支持狗运增加目标。

### 威·孙佳乐

**技能说明**

- **卷噬**：出牌阶段，你可以失去1点体力，然后从牌堆中获得一张红桃基本牌。
- **暴餮**：连招技（【桃】→【杀】），出牌阶段，完成此连招的【杀】结算结束后，你本回合使用【杀】的次数上限+1，然后从牌堆中获得X张黑色牌（X为你的体力值）。

**操作要点**

- 本人同一出牌阶段连续使用【桃】、【杀】后，在该【杀】结算结束后自动发动，不要求造成伤害。仅打出牌不构成连招。
- 使用其他牌会中断连招；卷噬等没有使用牌的技能不打断。每组连招发动一次，可反复完成；加杀次数本回合叠加，回合结束清除，未完成的连招在出牌阶段结束清除。
- 卷噬在出牌阶段不限次数。先失去体力，濒死依正常流程求救，仍存活才获得牌；暴餮按【杀】结算结束时的体力值取得黑色牌。
- 两技能只从牌堆筛选，不从弃牌堆补足；数量不足时获得剩余符合条件的牌，没有符合条件的牌时不获得牌，其他效果照常结算。

### 孙佳乐

**技能说明**

- **解囊**：出牌阶段限一次，你可以将所有手牌置于武将牌上，称为“铢”，视为使用一张【五谷丰登】。
- **吃食**：当你获得手牌后，你可以展示所有手牌。若均为黑色，你可以移去X张“铢”，弃置一名角色的一张牌（X为该角色到你的距离）；若均为红色，你可以移去Y张“铢”，视为使用一张【桃】（Y为你已损失的体力值）。
- **饕餮**：锁定技，你使用【五谷丰登】时多亮出X张牌；结算结束后，你获得其中未被选择的牌（X为你发动〖解囊〗的次数）。
- **饱矣**：觉醒技，每轮结束时，若“铢”的数量不小于存活角色数，你移去所有“铢”，执行一个额外回合。此回合你使用牌只能指定自己为目标。

**操作要点**

- 出牌阶段点击「解囊」，将所有手牌置为公开的“铢”，然后按原规则使用【五谷丰登】；每个出牌阶段限一次，空手牌时不能发动。
- 获得牌进入手牌区后，可发动「吃食」展示所有手牌。同色时选择是否移去“铢”；黑色分支的费用按目标到你的距离计算，可选择自己（距离为0），弃置目标手牌、装备区或判定区的一张牌。
- 红色分支按已损失体力值移去“铢”，视为使用一张【桃】，回复1点体力；“铢”不足、不能合法使用【桃】或取消支付时不执行该效果。
- 「饕餮」使用整局发动「解囊」的次数，本次「解囊」也计入；任意来源的【五谷丰登】均适用。各目标正常选择牌，全部结算结束后才获得未被选择的牌，已选走再弃置的牌不属于剩余牌。
- 「饱矣」在每轮结束时检查，存活角色数包括自己，整局仅觉醒一次。移去全部“铢”后立即执行额外回合；只有该回合使用牌须以自己为目标，群体锦囊也不能影响其他角色，打出牌仍按原规则处理。

### 扩展牌兼容

声明、响应和连招依据房间启用的卡牌登记信息与合法性接口判断，保留原牌效果。本扩展不附带其他卡牌包；具体兼容检查与55页规则覆盖清单见[规则审阅记录](规则审阅记录.md)。

## 多人联机

服务器与所有客户端需要安装相同版本的扩展及兼容补丁。连接组织者提供的服务器，进入同一房间，并确认房间允许使用相应扩展武将。

客户端安装扩展不能让任意公共服务器自动支持这些武将。本仓库未提供已部署的公网服务器；完整 GUI 对局与多人实战尚未验证。

## 发布与更新

把通过检查的源码提交到默认分支 `codex/initial-import`，GitHub Actions 会自动构建并发布稳定版本 `v0.2.运行编号`。朋友双击更新即可获取最新稳定 Release；仅上传源码需要等待自动发布成功。

更新器校验 GitHub 提供的 SHA256 和包内逐文件清单。当前更新范围是本仓库的武将扩展、5个兼容文件和更新入口；不会自动升级新月杀本体。游戏本体升级需另行制作匹配的补丁与懒人包。

仓库原名 `FreeKill_diy_sunjiale`，现名 `FreeKill_DIY_Extensions`。旧链接通过 GitHub 跳转继续访问；新版本更新器直接使用新地址。

## 检查范围

已通过37项原有技能场景和8项扩展牌兼容场景、Lua 5.4语法与核心注册检查、8项实际客户端检查，以及4项威·孙佳乐服务器结算检查。新增孙佳乐通过9项游戏自带框架的结算检查，覆盖全手牌费用、次数累计、重复锦囊结算、剩余牌归属、同色费用、取消支付、轮末觉醒和额外回合目标限制。

将 `tests/client_module_path.lua`、`tests/wei_integration.lua` 或 `tests/standard_integration.lua` 复制到已安装游戏的 `test/lua/`，可分别运行：

```text
FreeKill.exe --testfile test/lua/client_module_path.lua
FreeKill.exe --testfile test/lua/wei_integration.lua
FreeKill.exe --testfile test/lua/standard_integration.lua
```

更新器已检查首次安装、升级、重复运行、个人数据保留、校验失败、不安全路径、补丁冲突、写入失败回滚、下一版补丁及防降级。部分开发测试需要完整开发工作区与原版游戏文件。
