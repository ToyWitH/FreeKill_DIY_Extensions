孙佳乐 DIY 扩展（神·孙佳乐 / 威·孙佳乐）

目标版本：新月杀 v0.5.25。
人物：神势力、男性、4体力、4体力上限；称号：大胃菌王。
技能：逆天、唐氏、狗运、影黎。声明与用牌接口并入狗运。

新武将：威·孙佳乐，称号风卷残云；魏势力，男性，初始4体力、8体力上限。
卷噬：出牌阶段不限次数，失去1点体力，获得一张牌堆中的红桃基本牌。
暴餮：出牌阶段连续使用桃、杀后自动发动，本回合杀的次数上限+1，获得当前体力值张黑色牌。
中间使用其他牌会中断连招，每组连招可各发动一次。
卷噬等不使用牌的技能不会中断连招。黑色牌包含基本牌、锦囊牌和装备牌。
只从牌堆获得指定牌，不从弃牌堆补足；符合条件的牌不足时获得剩余符合条件的牌。

安装与游玩
请阅读压缩包根目录的“安装说明.txt”。
出牌和响应均点击“狗运”，声明后选择一张暗置手牌。
声明列表保留全部选项，当前不能合法使用或响应的选项显示为不可选。
使用真实牌，保留其属性与效果。
觉醒后声明基本牌、装备牌、普通锦囊牌或特殊（延时）锦囊牌。
普通锦囊牌指非延时锦囊；特殊（延时）锦囊牌指延时锦囊。
要求闪时只能声明闪；觉醒后声明基本牌，真实牌仍须为闪。
狗运装备增效：依次选择来源角色、接收角色及要移动的牌。
仅手牌对自己暗置，装备区保持明置。
暗置手牌不提供重铸等特殊用法，避免泄露牌面。
逆天只提供可合法自用的锦囊，其用牌不发动狗运。
成功通过狗运使用或打出牌计入觉醒次数，增效不另计次数。
